Why AIDP?

One reproducible analytical path

Workbench notebooks turn a defined input into validated Silver records, reusable Gold profiles and separately published scenario outputs. The dashboard consumes the serving projection—not private database credentials.

Evidence stays separate from assumptions

All inputs here are generated. A 100-participant stress test does not create 100 observed drivers. Timing equality is not physical overtaking. This demo excludes live telemetry, GPS, pit strategy and real-event forecasting.

A bounded, honest demonstration

Cloud execution requires an operator-configured AIDP environment. Monte Carlo runs on the notebook driver in this small example; distributed execution and Autonomous serving are not implemented in this public release.
